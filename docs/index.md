# InfluxDB Provider

Manages [InfluxDB](https://www.influxdata.com/) 1.x databases, retention policies, users and continuous queries. Tested against InfluxDB 1.11 and 1.12. InfluxDB 2.x and 3.x are not supported.

Requires Terraform 1.0 or later.

## Example Usage

```terraform
terraform {
  required_providers {
    influxdb = {
      source  = "DrFaust92/influxdb"
      version = "~> 2.0"
    }
  }
}

# The URL and credentials can also come from the INFLUXDB_URL,
# INFLUXDB_USERNAME and INFLUXDB_PASSWORD environment variables.
provider "influxdb" {
  url      = "https://influxdb.example.com:8086/"
  username = "terraform"
  password = var.influxdb_password
}

# A server with a private CA that requires client certificates. Requests
# also go through the proxy in HTTPS_PROXY, unless NO_PROXY excludes the host.
provider "influxdb" {
  alias              = "tls"
  url                = "https://influxdb.internal:8086/"
  ca_certificate     = file("${path.module}/ca.pem")
  client_certificate = file("${path.module}/client.pem")
  client_key         = file("${path.module}/client-key.pem")
  timeout            = "5m"
}
```

## Schema

### Optional

- `ca_certificate` (String) PEM-encoded CA certificates used to verify the server certificate, instead of the system roots. Can also be set with the `INFLUXDB_CA_CERTIFICATE` environment variable.
- `client_certificate` (String) PEM-encoded client certificate, for a server that requires TLS client authentication. InfluxDB 1.x does not request client certificates itself; use this with a TLS proxy or load balancer in front of it that does. Set it together with `client_key`, both in the configuration or both in environment variables. Can also be set with the `INFLUXDB_CLIENT_CERTIFICATE` environment variable.
- `client_key` (String, Sensitive) PEM-encoded private key of `client_certificate`. Can also be set with the `INFLUXDB_CLIENT_KEY` environment variable.
- `password` (String, Sensitive) InfluxDB password. Can also be set with the `INFLUXDB_PASSWORD` environment variable.
- `skip_ssl_verify` (Boolean) Skip TLS certificate verification. Can also be set with the `INFLUXDB_SKIP_SSL_VERIFY` environment variable. Prefer `ca_certificate` for servers with a private CA.
- `timeout` (String) Timeout of each request to InfluxDB, as a duration such as `30s` or `5m`. Can also be set with the `INFLUXDB_TIMEOUT` environment variable. Defaults to `2m`.
- `url` (String) InfluxDB connection URL. Can also be set with the `INFLUXDB_URL` environment variable. Defaults to `http://localhost:8086/`. Requests go through the proxy set in the `HTTPS_PROXY`, `HTTP_PROXY` and `NO_PROXY` environment variables.
- `username` (String) InfluxDB user name. Can also be set with the `INFLUXDB_USERNAME` environment variable.
