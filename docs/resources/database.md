# influxdb_database (Resource)

Manages an InfluxDB database and its retention policies.

## Example Usage

```terraform
resource "influxdb_database" "metrics" {
  name = "awesome_app"
}

resource "influxdb_database" "example" {
  name = "example"

  retention_policies {
    name     = "2days"
    duration = "48h0m0s"
  }

  retention_policies {
    name     = "12weeks"
    duration = "2016h0m0s"
    default  = true
  }

  retention_policies {
    name               = "1week"
    duration           = "168h0m0s"
    shardgroupduration = "2h0m0s"
  }
}
```

## The `autogen` retention policy

InfluxDB creates an `autogen` retention policy with every database. It is not tracked while it has
its default settings and is not in the configuration. To manage it, add a `retention_policies` block
named `autogen`: the existing policy is then altered instead of created. Removing that block later
drops the policy.

### Nested Schema for `retention_policies`

Required:

- `duration` (String) How long data is kept, e.g. `24h0m0s`. `0s` keeps data forever.
- `name` (String) Name of the retention policy.

Optional:

- `default` (Boolean) Whether this is the default retention policy of the database. Defaults to `false`.
- `replication` (Number) Replication factor. Defaults to `1`.
- `shardgroupduration` (String) Shard group duration. Defaults to `1h0m0s`.
